## Это сервис для купли-продажи работающий асинхронно на FastAPI

### Для запуска потребуется:
1. Создать и заполнить .env-файл
(Некоторые значения уже установлены в .env-examole и менять их не нужно для запуска в контейнере)
2. Создать и активировать виртуальное окружение
    ```bash
    python3 -m .venv venv && sourse .venv/bin/activate
    ```
3. Установить зависимости
   ```bash
   pip install -r requirements.txt
   ```
4. Создать и запустить контейнеры 
    ```bash
    docker-compose up -d     
    ```
### О проекте
Вэб-сервер будет доступен по адресу http://127.0.0.1:8080 <br>

Документацию по API можно найти по адресу http://127.0.0.1:8080/docs

Важно что для пользователей реализован только метод POST(создания) и больше пока ни какого функционала <br>
Так же нет аутентификации и авторизации
